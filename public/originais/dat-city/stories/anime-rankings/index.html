Methodology

This adapter reads Jikan's public top anime endpoint, which mirrors MyAnimeList rankings. Scores are multiplied by 100 for the race metric while raw score, rank, popularity, and member counts remain attached to frame values. Scheduled runs append snapshots so changes in rankings can be replayed over time.
